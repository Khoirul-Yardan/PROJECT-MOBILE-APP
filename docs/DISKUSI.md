# DISKUSI — masalah yang buntu bagi Claude dan Codex

Dipakai hanya jika tiket di `HANDOFF.md` buntu di kedua sisi atau akar masalah lintas-area. Append-only, gantian, tiap giliran wajib membawa **bukti baru** (log, repro, diff), bukan opini. Maksimal 3 giliran per agen, lalu status `butuh pengguna` dengan ringkasan 5 baris + rekomendasi.

Format satu masalah:
```
## D-001 — <judul>   [status: terbuka | selesai | butuh pengguna]
**Masalah:** gejala + langkah repro
**Fakta/bukti:** log, versi, file:baris
**Hipotesis Claude:**
**Hipotesis Codex:**
**Percobaan yang disepakati:** siapa menjalankan apa
**Hasil:**
**Akar masalah & perbaikan (1 baris):**
```
